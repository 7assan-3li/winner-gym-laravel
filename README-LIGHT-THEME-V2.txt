WINNER GYM — Light Theme Completeness Fix v2

This is a small overlay patch for the already-installed dual-theme version.
It does not change layout, permissions, database tables, sizes, or dark theme.
It only completes light-mode colors and bumps the theme CSS cache version.

Install:
1) Extract over the Laravel project root.
2) Run: php artisan optimize:clear
3) Hard refresh once (Ctrl+F5).

No migration. No npm build required.
