WINNER GYM — Final Dual Theme Layer

What this patch does:
- Keeps the accepted RTL layout, dimensions, spacing and typography unchanged.
- Adds a centralized light-theme layer loaded after every module stylesheet.
- Covers Dashboard, Members, Subscriptions, Attendance, Payments, Expenses,
  Inventory (products/purchases/sales/POS), Nutrition, Reports, Administration,
  Staff, Permissions, WhatsApp, Backups and Settings.
- Keeps semantic accents (blue/green/red/orange/purple) while converting surfaces,
  borders, forms, tables, modals, dropdowns, pagination and overlays to a calm light UI.
- Persists the selected theme in localStorage and survives Livewire navigation/full reloads.
- No database migration and no npm build required.
