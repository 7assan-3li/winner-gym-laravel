# قواعد التطوير الإلزامية لنظام WINNER GYM

1. **الطبقات المعمارية**:
   - لا تضع أي استعلامات أو عمليات تعديل مالي أو مخزني داخل `Livewire` أو `Blade` مباشرة.
   - كافة قواعد العمليات تمر حصراً عبر الـ `Services`.

2. **الأمان المالي**:
   - كافة التعديلات المالية والمخزنية تنفذ داخل `DB::transaction()` مع `lockForUpdate()`.
   - تسجيل إلزامي لكل حركة في `audit_logs` عبر `AuditService`.

3. **العملات**:
   - منع خلط أو دمج عملتي الريال اليمني (`YER`) والريال السعودي (`SAR`).

4. **المخزون والاشتراكات**:
   - حساب تكلفة الشراء بالمتوسط المرجح المتحرك.
   - منع تداخل الاشتراكات لنفس العضو والالتزام بنسبة الدفعة الأولى (50% كحد أدنى) في التقسيط.
   - فحص شروط الحضور (صلاحية الاشتراك، عدم وجود أقساط متأخرة، ساعات العمل).

5. **الصلاحيات**:
   - فحص الصلاحيات عبر `PermissionService` وميدلوير `gym.any` / `gym.owner`.
