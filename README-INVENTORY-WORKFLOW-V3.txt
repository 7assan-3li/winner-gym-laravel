WINNER GYM — Inventory Workflow V3
==================================

الفكرة التشغيلية:
1) المنتجات: تعريف المنتج مرة واحدة (الاسم، الصورة، الباركود، سعر البيع، الحد الأدنى). يمكن إدخال رصيد افتتاحي فقط عند بدء استخدام النظام.
2) المشتريات: أي بضاعة جديدة تسجل كشراء معلّق. بعد وصولها فعلياً يتم اعتماد الشراء فتزيد الكمية تلقائياً ويُعاد حساب متوسط تكلفة المنتج.
3) المبيعات: شاشة نقطة بيع واضحة. اختيار المنتج -> الكمية -> العميل/طريقة الدفع -> تأكيد. عند التأكيد ينقص المخزون ويحفظ البيع ويظهر الإيراد في المالية.

مهم محاسبياً:
- المشتريات المخزنية لا تُسجل تلقائياً كمصروف تشغيلي، حتى لا تُحسب تكلفة المنتج مرتين.
- تكلفة المنتج تدخل في حساب ربح المنتجات عند البيع عبر تكلفة البضاعة المباعة.
- المبيعات المكتملة تدخل في إيرادات المنتجات في المالية.

ما يتضمنه التحديث:
- شاشة المنتجات المحسنة + صور المنتجات + رصيد افتتاحي + بيع سريع.
- شاشة مشتريات كاملة مع المورد، فاتورة المورد، طريقة الدفع، الاعتماد والإلغاء.
- شاشة مبيعات/POS كاملة مع سلة، أعضاء/عملاء، نقدي/تحويل، خصم حسب الصلاحية، سجل وإلغاء البيع.
- توافق صور المنتجات القديمة المخزنة على disk=local والجديدة على disk=public.
- متوسط تكلفة مرجح عند اعتماد مشتريات جديدة لرفع دقة قيمة المخزون والربح.
- صلاحيات inventory.manage متوافقة مع إدارة المنتجات والمشتريات والمبيعات.

التثبيت:
php artisan migrate
php artisan optimize:clear

لا يحتاج npm run build.
